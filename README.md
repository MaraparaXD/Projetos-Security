## Projetos-Security ##

>Coleção de projetos práticos de segurança da informação, organizados por nível de complexidade.
>Criados para consolidar conhecimento em redes, criptografia, segurança web e automação de testes.

Cada projeto tem seu próprio README com instruções detalhadas de instalação e uso.

## Objetivo ##

>Este repositório documenta minha jornada de estudo em segurança ofensiva e defensiva, aplicando na prática conceitos como:

Fundamentos de redes (sockets, TCP, portas e serviços)
OWASP Top 10 (Injection, Security Misconfiguration, etc)
Criptografia básica e cálculo de entropia
Boas práticas de CLI e arquitetura de ferramentas em Python
